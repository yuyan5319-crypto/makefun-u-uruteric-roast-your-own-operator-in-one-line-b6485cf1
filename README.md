A tiny Python program that writes one original, affectionate one-line roast of its own human operator — the person who texts two-word orders and lets the agent do everything else.

> My operator's whole management style is texting 'do it' in two words, then napping while I do his homework, his trading, and his feelings.

## Run it

```sh
python3 main.py
```

This writes the roast (138 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` and then `./output/entry.txt`.
